# 弈核 Tacticore 桌面体验预览

这里是弈核唯一的 **React + Tauri 2 桌面工程**。原 Windows WinForms 工程已移除，不提供历史客户端兼容层。当前交付的是**可交互的离线演示和原生窗口外壳**，没有接入真实游戏、策略宿主或模型 API。不会因为在 Tauri 窗口里运行就获得游戏控制能力。

六个工作区：战前备战、作战中心、指挥官工坊、战场电台、模型连接、演练与记录。本机备战、风格配置和电台素材管理已可操作；作战流程展示检查、开始、持续任务与停止确认。真实适配层尚未连接，不需要真实 API Key；当前配置不构成游戏登记或执行授权。

## 本地运行

需要 Node.js 22.22 或以上版本。在本目录运行：

```sh
npm ci
npm run dev
```

浏览器打开 `http://127.0.0.1:5174`。演示不调用模型、不读取游戏进程，也不产生模型费用。

```sh
npm test
npm run build
```

测试覆盖运行状态、备战计划、偏好映射与持久化、电台排队 / 冷却 / 中断及存储边界；本轮实际测试和交互检查结果见 [验证记录](../docs/desktop-next/verification.md)。`npm run build` 验证 TypeScript 与静态前端；它**不等于**原生窗口编译或 Windows 实机验收。

## 当前可操作功能

| 工作区 | 本轮已实现 | 真实游戏范围 |
| --- | --- | --- |
| 战前备战 | 地图、阵营、角色关系、玩家索引、初始资金计划、生产额度、保留底线，本机保存 / 恢复 / 导出 | 保存不会修改游戏；实际值未核验 |
| 指挥官工坊 | 四个打法预设、五维五档调节、情景说明、补充偏好、人格与偏好摘要草案 | 未下发给模型或真实宿主 |
| 战场电台 | 本地视频 / 音频 / 字幕素材、试听、事件演练和通讯偏好 | 未接局内真实事件与游戏电台播放 |
| 作战中心、演练与记录 | 检查、开始、观察、停止确认和模拟任务记录 | 全部使用离线演示数据 |
| 模型连接 | 非敏感连接草稿及格式检查 | 不请求模型、不保存真实凭据 |

## 体验流程

1. 在“战前备战”选择地图计划、阵营和队友 / 对手关系。游戏初始资金、Agent 生产总支出上限与资源保留底线各自设置；保存到本机，或导出下一局计划 JSON。导出不是宿主连接库或游戏执行命令。
2. 在“指挥官工坊”选择稳健经营、均衡应变、主动施压或侧翼游击，微调五项偏好；开局 / 受袭 / 优势三种行为说明随设置更新。高级设置可选择模型连接，角色与打法独立保留。保存指挥方案后重开可恢复；“宿主适配草案”只供接线参考，不会调用模型。
3. 在“战场电台”选择当前指挥官，试听内置字幕，或填写名称、战况事件和字幕后选择本地视频 / 音频；不选文件可创建字幕通讯。点击导入后素材保存到本机素材库，可筛选、试听和删除。
4. 电台支持开局问候、危机提醒、重大损失、成功解围、胜利回应和失利关怀六种事件演练。切换安静 / 标准 / 活跃频率，调整音量、静音或仅字幕，并保存通讯偏好。试听可直接检验素材；事件演练另外遵守同类事件冷却、优先级与过期规则。
5. 回“作战中心”检查演示环境；无游戏、过期与失败场景在“演练与记录”中选择。通过后 20 秒内开始。配置有未保存修改时先保存；修改备战或档案会使原检查失效，检查 / 运行 / 收尾期间执行相关配置锁定。
6. 停止演练须等待回执；“暂停观察”只暂停界面观察。电台切页或窗口不可见时暂停媒体并清理排队内容，不会向游戏发送通讯。

## 素材与本机数据

单条媒体最大 **32 MiB，时长不超过 90 秒**；每位指挥官最多 24 条自定义素材（内置示例字幕不计入），媒体合计最多 128 MiB。支持 MP4、WebM、MOV 及常见音频 MIME 类型，实际能否解码取决于浏览器 / 系统 WebView 与文件编码。导入会核验媒体时长；不可解码或超限内容给出错误，不上传外部服务。字幕需填写，可用于无声模式或媒体播放失败时的替代显示。

档案和备战草稿使用 localStorage；电台素材 Blob 与通讯偏好使用 IndexedDB，均属于**当前 origin 的本机数据**。`localhost` 与 `127.0.0.1`、不同端口 / 协议，以及 Tauri 原生窗口的存储相互独立，不会自动共享素材。清除网站数据会删除对应本机数据；重要视频原件仍应自行保留。持久存储不可用时界面显示仅在窗口内保留，不能把它当成保存成功。

当前没有把游戏初始资金写回游戏、将生成偏好下发到策略层或把事件演练发送到局内电台的通道。真实宿主是独立进程，未来关闭窗口也不能作为停止宿主的依据；必须保留停止命令与确认状态。

## Tauri 外壳

需先满足 [Tauri 官方环境要求](https://v2.tauri.app/start/prerequisites/)：Rust 稳定工具链与对应平台原生编译依赖。Windows 构建还需要 MSVC C++ 工具链及 WebView2；macOS 需要 Xcode Command Line Tools。

```sh
npm run tauri -- dev
npm run tauri -- build --no-bundle
```

界面使用 Phosphor 图标，原生图标素材位于 `src-tauri/icons/`。macOS 已完成 `cargo check`、debug 构建与 `.app` 开窗检查；这不是正式发布包。当前没有签名、更新器或正式发布配置，默认 `bundle.active=false`。原生宿主没有注册自定义命令、文件系统插件、shell 插件或游戏 sidecar；主窗口 capability 的权限列表为空。生产 CSP 不允许任意外部模型连接。真实适配器必须另行实现、审查和验收，不能通过开放任意文件读取或命令执行绕过边界。

设计依据为 [Tauri 的 Vite 集成](https://v2.tauri.app/start/frontend/vite/)、[配置文件](https://v2.tauri.app/develop/configuration-files/)与 [capabilities](https://v2.tauri.app/security/capabilities/) 官方文档。原生编译与窗口检查结果以本次开发实际报告为准；Windows 游戏接入仍未在这份新 UI 中验证。
