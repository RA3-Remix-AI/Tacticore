# Windows v0.1.0-beta.3 本地验收与交付摘要

冻结候选 `windows-beta3-v11` 的既定 P0/P1 与 F01–F07 按下表范围完成；同一普通配置的三局新自然验收通过 3/3。2026-11-07 新普通账户的安装、首次配置和重开补验关闭了最后的 F05 缺口。完整原始运行与历史失败保留在本机验收目录；此报告提供可迁移的有界摘要和原件摘要索引，不将原始数据库、账户凭据或完整未脱敏流量放入源码／交付包。

| 门槛 | 结论与范围 |
| --- | --- |
| F01 接管边界 | 通过：模型决定高层意图；具体建造、生产、单位微操仍属原生 AI |
| F02 战略判断 | 有界通过：57 条真实接受并提交判断有合法事实、理由和保持／重评条件；不等于最优策略或精确战损事件源 |
| F03 原生联通 | 有界通过：十四入口的采用／等待与后轮判断有证据；防守等待和已开启的调度门不冒充新任务或新产出 |
| F04 闭环记忆 | 有界通过：效果与阻碍到达后轮；扩张窗口内活动经明确历史效果及到期结果进入后轮接受判断；同窗直接接受新意图的更强检查未通过 |
| F05 日常客户端 | 通过：已配置账户的升级及完整普通对局流程，另有新普通账户空白安装、实际配置、正常关闭重开；未验证其他机器 |
| F06 生命周期 | 通过：停止、取消、旧局隔离及完整独立归还；最终 52 条原始运行已核验，旧失败仍保留 |
| F07 综合自然局 | 通过 3/3：同一 V11、普通风格、两张地图与三个新游戏进程，不借用研究局或旧候选 |

三局为无限岛 N01（16:17，受控方败）、原始神庙 N02（19:33，受控方胜）、无限岛 N03（14:41，受控方胜）。共 107 次真实请求、104 次响应、81 次接受、23 次拒绝、两次连接失败及一次结算取消；胜负不是通过条件，也不建立模型独占战果归因。三局的完整脱敏诊断、离线过程页和原生录像均收录在本地交付包 `evidence/N01`、`N02`、`N03` 中。

新账户仅属本机普通 Users 组。其安装器退出码为 0，3953 项运行时文件与 V11 一致，普通风格保存为修订 2，正常重开后配置和有效摘要一致，运行记录为空。本项未新增游戏、Host 或模型调用，正式信用仍为 3/3。最终复核有 91 个唯一原件引用摘要正确、8954 项冻结文件未变。

`acceptance-summary.json` 为可迁移摘要；`evidence-index.json` 记录本机权威原件的仓库相对路径、大小和 SHA-256，其中原件不一定随源码分发；`source-pins.json` 绑定 999 份实际冻结源码；`artifact-identity.json` 保留原 V11 制品身份。源码版本提交发生在制品构建之后，原安装包不重建，构建时工作区基于 `36bac49b` 且未提交。

验收仅覆盖已核验 RA3 1.12 繁中配置、TemplePrime / InfinityIsle、P3 苏军中等 AI 位置 2、P4 原生中等电脑和 DeepSeek / deepseek-flash。用户无其他验收机器，跨机器及全新 Windows 机器未验证；本机普通账户首用不替代该项。

原生录像提前结束缺陷、同一扩张窗口内接受新意图的更强检查、防守实际活动和模型服务持续可用仍未通过或未证明。完整限制见 [发布说明](../../docs/windows-v0.1.0-beta.3-release-notes.md)，操作见 [玩家说明](../../docs/windows-v0.1.0-beta.3-player-guide.md)。本地版本标签不代表公开发布，未创建公开下载地址。

交付整理时的源码回归：本机完整材料下 212 项 Python 检查、133 项前端检查及类型检查通过。隔离暂存源码快照下，212 项 Python 检查无失败或错误，其中 6 项因未分发的本机历史上下文／证明跳过；前端 133 项及类型检查通过（复用已锁定依赖，无新安装）。原始缺少测试夹具的隔离快照失败记录保留，补齐 Git 已有夹具后重核；不把跳过检查计为新增通过。
