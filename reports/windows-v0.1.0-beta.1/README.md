## 限制

- 仅 RA3 1.12 已核验繁中配置、TemplePrime、P3 苏军和已验证出生位置、P4 原生电脑对手。三局采用中等难度、对手随机、10000资金、无宝箱及人类观察者。
- 已验证现有用户的实际安装/升级及客户端流程；未验证干净 VM、全新用户、其他 Windows 版本或任意机器。安装器未签名，无自动更新。
- 安装包不含游戏、Mod BIG、SDK 或编译器；用户须另备兼容游戏和 Mod，并自行配置模型连接。
- 十四项入口的通过是语义匹配的采用/拒绝/等待，不能承诺每次完成任务。扩张补充局有任务活动和移动，但活动反馈未赶上后轮模型，较强的逐项闭环仍未通过；建设/生产的“推进”证据包含原生已启用基线。
- STOP 归还后原生 AI 可继续；同一已停止游戏进程不能重新接管，须新开游戏进程。原生录像不单独证明外部宏观意图的重放保真。
- 重大损失/基地遇袭的通用实机事件源、其他地图/阵营与跨机器兼容仍待后续版本；不承诺模型服务持续可用或胜率提高。
