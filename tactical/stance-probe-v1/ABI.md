At most one unacknowledged pulse is posted. The bound command/task/seq/token and original game thread are verified. Native acknowledges paused or duplicate-frame transport without running the body, and calls the body no more than once per actual logical frame. Install attempts an inline body on that same thread. Input-prefix mutation is rejected; the original private prefix is reinstated solely to safely clean up the originally bound actor. The scene or invalid-actor branches never call an old actor/module address.

The raw `disposed` flag means actor identity/health became invalid, not proof that its ID left the world list. `scene_changed` likewise is an observed lifecycle guard, not a live actor Return claim. Only actual Transfer/Remove/Add plus default pool membership can prove live control Return. Independent scene/disposal evidence would be required for those separate outcomes.
