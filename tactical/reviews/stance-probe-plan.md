## Budgets and truthful terminal handling

Overall deadline is fixed at initialFrame+300 and a30-second host wall deadline; neither is renewed. Initial settling and cleanup each retain the60-frame limit. A host disconnect/stop uses the same restoration/normal-return path, with a bounded drain. Paused game state does not authorize calls or fictitious Stop samples; if restoration cannot advance while paused, report pending ownership and require a real resume instead of claiming released. No second native channel may start until actual inertness and control release are proven.

Loss of identity/owner, death, scene teardown, or an unrestorable stance is a separate failed/unknown outcome. Never invoke a saved module address after its Thing binding fails. Never claim a live actor returned or original stance restored merely because a counter changed. A scene/death reader can separately prove disposal/exclusive-control release using the existing exact process/request binding; it cannot prove stance restoration or physical Return.
