# 临界输入容量一致性修复 · 2026-10-31

当前源码已修复提示示例随 JSON 对象键顺序变化的问题。准备阶段和 SDK 发送阶段从同一事实目录选择相同的示例引用：已有、非未知的 `own.credits` 优先，否则按键排序选择已有事实。不添加事实，不修改真实战况或策略权限。

原故障中，准备阶段选择 `own.credits`，SDK 隔离请求时排序键后选择 `capabilities.actions`，提示增加9字节，估算从16379B变成16388B，导致联网前拒绝。修复后两阶段均为16379B。16KiB输入门和1536B策略记忆门保持不变，真实超限仍拒绝。
