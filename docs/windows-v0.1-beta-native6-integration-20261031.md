# Windows beta：Native6 资格、观测与停止归还接入

本批把受信资格、合法己方观测与 Host 生命周期接到可迁移运行包，默认动作仍是十四项高层意图。具体建筑、选址、队列、兵种数量、协同及单位操作由原生 AI 决定。当前交付为软件层有界试运行候选；公开发布、安装器、新候选 F01–F07 与自然三局均未通过。历史 v9 与首批 Native6 离线候选保持原结论和原文件。

## 资格与合法观测

- 新 schema14 描述符只有版本、类别、运行根和完整清单 SHA 四个字段。它必须与安装位置、受信原生启动器编译的清单摘要一致；debug 启动器主动清除继承授权。模型、WebView、自报通过字段和旧 schema13 都不能赋予 Native6 权限。
- 构建期逐字节核验原资格报告、模板安全审计、Mod/游戏身份、视野算法、113 份模板 XML 来源和原始视野证据。运行包只保存必要的安全模板、签名、注册及编译身份数据和原件摘要，不复制 XML、游戏、SDK、编译器或历史报告。
- `--field-candidate` 必须先通过上述数据核验，生成独立闭包和二进制。默认构建仍禁止附着。开启有界试运行不代表产品通过；清单始终记正式局零、产品资格 false。
- 每局仍执行本局原生签名、P3 电脑指挥官 UUID 链、己方完整清晰足迹、稳定视野和当前对象指针握手。旁观者视角不能回退供情报，隐形检测未获资格，继续保守排除。未新增伤亡/基地遇袭事件生产者，`events=[]` 的限制保留。
- 战略观测器借用本次 SDK 的映射、绑定及只读句柄，核验真实 PID/原始创建时间、完整封存绑定、两帧/250ms 窗口及严格后续已完成回调。带旧协议或其他封存绑定摘要的样本拒绝进入战略反馈。

## Host、STOP 与独立归还

Host 从包内构造 Native6Scope、采样器和运输，不回读开发机资格档案。冻结描述符、会话、绑定、运行清单、Native 清单和资格数据；运行中保留源码和会话读共享锁。发布与恢复都绑定受信清单摘要及本次 Host 身份。

普通 STOP 先提交同一持久屏障，随后阻止新模型请求、新 Native 构造和新执行批次。返回成功需要独立原生基线、旗标、租约、完整日志、当前 OS 身份与实际 helper 退出状态；ACK 或单个 cleanup 标志不足以发布归还。尚未构造运输的早停也必须有独立无接管证明和无构造/派发历史。

Host 意外结束后的恢复采用单独 Native6 合同：只打开已有 FILE_MAP_READ，重新采集同一实例、同一租约的原生基线和日志；要求明确 STOP 与原进程已结束。未观测的 helper 退出码保持 null。未决高层指令保留 uncertain；恢复不重放命令，不改变同时存在的控制 RPC。正常返回与孤儿返回不会互相冒充。

完整依赖持锁的首用离线实测耗时 8,766ms，暴露了 candidate-c 的旧 8 秒附着等待不够的问题。保留该候选及失败结论；新 candidate-d 将首次准入等待限定为 30 秒，并在实际 helper 启动后、等待附着 ACK 前封存身份，覆盖等待中 Host 丢失的窗口。该身份记录不宣称附着或归还成功。STOP 屏障的 45 秒等待、心跳失效的 5 秒界限、意图有效期和停止归还的 8 秒等待均未扩大。真实首用延迟仍待实机测量。

复用的 V5 控制器名称和 `native_strategic_v5` 账本操作代表既有高层合同版本。Native 映射、ABI、绑定、日志、独立归还与资格全部使用 V6，旧 V5 实机证据不能充当 V6 归还证明。

## 复核缺口 N6-R1：完整持锁

首批离线候选只将依赖源文件列入完整清单，没有全部纳入 Native 持续输入锁。该缺口保持在原复核记录中。

本批把适合 ZIP 导入的纯 Python 依赖及其 checked-hash 缓存、资源和声明放入固定 `site-packages.zip`，保留含原生扩展或使用 `__file__` 的包在文件系统。标准库、保留依赖的源码/缓存、Python 二进制、固定导入表、容器、容器成员清单和资格数据全部进入编译输入锁。许可证清单给出实际文件或 ZIP 成员位置；再分发审查仍标 pending。

Native 的 4096 总句柄/4093 源输入上限不变。离线持锁探针直接编译包含冻结 `native.cpp` 的单独 EXE，只调用原有路径与 `lock_hash` 函数；对所有输入尝试打开写/删除权限句柄，预期均因共享冲突拒绝，随后检查退出释放及包内容不变。探针不启动 Game、hook、Native 控制或真实模型。真实游戏内的回调开销和直到进程退出的持锁行为还须实机复核。

最终 candidate-d 完整包已通过：真实编译布局与 profile、受信摘要准入及失败拒绝、包内 Host 配置、真实 SDK MockTransport 的 OpenAI/DeepSeek 请求和 16KiB 临界容量、中文/空格目录迁移、输入持续持锁和首用/查询/重开 RPC。3440 个输入的 6880 次写/删除权限句柄均被共享拒绝，持锁探针退出 0；候选内容保持不变。模型请求均为合成内存模拟，真实模型请求零，Game 访问零。
