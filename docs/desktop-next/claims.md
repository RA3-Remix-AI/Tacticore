# 品牌与宣传表述边界

品牌名称统一为 **弈核 Tacticore**。它是独立 Agent 指挥程序；**Remix-Ai** 是基于 Remix 037 的游戏内容适配版本。两者分别维护。唯一桌面工程为 React + Tauri 的 `desktop-ui/`；原 Windows GUI 已移除，不能将其历史功能算作当前界面已交付能力。

推荐主句：**让模型的判断进入真实战场。弈核 Tacticore 正在验证从观察、推演到行动与反馈的指挥闭环。**

| 主题 | 当前可用 | 需要标记规划或补实机证据 |
| --- | --- | --- |
| 产品阶段 | 面向 RA3 的独立 Agent 指挥系统，开发验证中 | 通用跨游戏平台、任意 Mod 即插即用 |
| 模型连接 | 宿主 CLI 默认使用 PydanticAI，支持已校验的 OpenAI 兼容配置；DeepSeek 有历史实局记录 | 当前桌面可连接真实模型、所有服务商/所有最强模型均通过实战 |
| 决策链 | 已有受视野约束的模型决策、持续记忆与限定执行链记录 | 完全自主接管所有经营与战斗 |
| 战术效果 | 限定征召兵场景完成长接近、短袭和撤退闭环 | 可靠全兵种微操、经济压制、失视野重获命中 |
| 完整对局 | 历史记录中一次模型链路贯穿完整遭遇战 | “模型击败原生电脑”——胜利不能归因模型，正式局战术任务未完成 |
| 性格 | 可编辑突击、经营、游击等偏好 | 性格形成稳定可辨认打法，需多局对照 |
| 多 Agent | 未来探索多 Agent 并肩与对抗 | 多个档案不等于多电脑同时执行已通过 |
| 桌面 | 唯一 React + Tauri 工程，可交互离线预览；macOS debug 原生窗口已检查 | Windows 实机 GUI 已接入游戏、开箱即用、一键实战 |
| 开源 | 源码与网站、Mod 工程分别维护 | 正式许可、发布支持范围需另行确定，公开仓库不替代 LICENSE |

当前 UI 的截图、录屏和动效都须标“离线演示 / 概念流程”。历史实机截图仅用于说明对应版本和测试日期的研究结果，不能当作当前可用 GUI。不要把离线成功计数、模拟任务与历史实战数拼接成一场真实演示。使用实际游戏或 Remix 素材时保留原权利归属与学习交流、非商业说明；这不表示获得了额外授权。
