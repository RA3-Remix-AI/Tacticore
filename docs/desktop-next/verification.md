# 本轮验证记录

日期：2026-10-25。环境：macOS arm64。此记录描述开发验证，不是 Windows 游戏验收。

## 三个 Feature 的本机实现增量

- 当前前端测试共 **32 项全部通过**：原运行契约与存储 12 项、指挥偏好 6 项、备战计划 4 项、电台 10 项。
- TypeScript、Vite 和包含最新界面及本地媒体 CSP 的 Tauri macOS debug `.app` 构建通过。
- 实际打开新 `.app`，确认六个工作区入口、原生窗口 IndexedDB 素材库就绪，点击开局场景后正常播放示例字幕。原生窗口的数据与浏览器预览分开。
- 浏览器实际检查：备战金额与阵营保存后刷新恢复，跨页草稿阻止检查，运行中备战字段锁定，停止需确认收尾回执。
- 工坊：选择均衡预设后用键盘将侦察调至第五档，行为预览即时变化，保存后能恢复。四种产品预设仍只映射到三种现有宿主人格。
- 电台：导入本地合成 WAV 与 MP4 测试片段并保存至 IndexedDB，刷新后恢复；两种媒体均实际播放（媒体就绪、无解码错误），仅字幕模式移除媒体元素，离开页面停止解码。未调用语音或视频生成服务。
- 场景预览中，危机立即替换庆祝；同类冷却、旧会话隔离、过期队列与异步保存/播放边界通过单元测试和独立审阅。
- 三个工作区在 390×844 视口均无横向溢出；1366×900 下检查桌面布局。页面切换归顶；反馈提示不再遮挡底部启动操作。
- 本机媒体和界面设置按当前 origin 保存，浏览器预览与 Tauri 窗口不会自动共享数据。本轮合成测试素材不加入源码或发布物料。

以上证明本机配置、预览与素材工具可操作；游戏资金写入、偏好送入真实模型、局内事件驱动电台和 Windows 原生适配器仍待目标环境实现与验收。下方保留首次桌面外壳的验证范围。

## 桌面工程

- `npm test`：12 项通过，涵盖运行状态、请求去重、取消、超时就绪、配置修订、订阅重入清理和非敏感设置存储。
- `npm run build`：TypeScript 检查与 Vite 构建通过。
- `cargo check`：通过。
- `npm run tauri -- build --debug --bundles app`：生成 macOS 开发应用；实际通过原生窗口打开，WebView 正常显示。
- 浏览器检查：1366×768、390×844；窄屏无横向溢出，演练控制区保持可见。
- 交互检查：无效地址提示；修正后保存；无游戏场景阻止开始；就绪后开始；停止确认、等待回执、最终“演练已停止”。
- App 热更新后自动整页重载，重新检查可正常运行，不复用已销毁的 runtime。
- 最终浏览器控制台无 error / warn。
