# Windows v0.1.0-beta.1 使用说明

本文件随安装候选准备，发布资格以同一安装候选的独立验收记录为准。源码测试和旧 v9 的三局不能代替本版本验收。

## 安装与准备

使用 Windows x64 安装器 `Tacticore_0.1.0-beta.1_x64-setup.exe`，按当前用户安装。安装包附带 Python 和运行依赖，无需安装开发环境；首次安装 WebView2 时可能需要联网。

安装包不包含《红色警戒 3》、游戏素材或 Mod BIG。请准备合法取得的 RA3 1.12 以及与本版本资格匹配的指挥官 Mod；普通原版或其他任意 Mod 不会通过核验。当前受支持文件 SHA-256：

| 文件 | SHA-256 |
| --- | --- |
| `Data/RA3_1.12.game` | `ec230c6ae1eaee30b0b4fa6ba29d417c974ecae46d6715dfbe786a815935c165` |
| 兼容指挥官 Mod BIG | `66025609e788ed18f8eb55b1722e6c197a373f387137b69e6b04118d0a5278f0` |

1. 打开客户端，在“游戏接入”依次选择自己的游戏文件与兼容 Mod，点击“核验并准备”。客户端核验文件并登记启动入口，无需修改 JSON。
2. 在模型连接中配置自己的 provider、模型和密钥。密钥不进入发布物或验收交接文件，模型使用可能由 provider 收费。
3. 点击“启动受支持游戏”。在游戏中进入受支持对局，再回客户端点击“发现游戏”，准备会话并预检。
4. 预检通过后启动指挥官，观察模型理由、原生采用/等待/拒绝及后续反馈。点击“停止”后等待独立归还确认，再退出游戏或进入下一局。

## 支持范围

当前限定 TemplePrime（内部 ID `map_mp_2_black1b`）、P3 苏军、P4 原生电脑对手及已验证出生位置。其他版本、阵营、地图、位置和 Mod 不在本次保证范围内。停止后若要重新接管，应退出当前游戏进程并准备新游戏会话。

模型决定进攻、撤退、侦察、扩张及推进/暂缓发展等高层意图。具体建筑、位置、顺序、兵种与数量、寻路、阵型、交战和技能由原生电脑 AI 执行。指令被接受不表示战略成功，本版本不承诺提高胜率。

## 停止、升级与诊断

停止后原生电脑 AI 可以继续游戏。客户端须确认独立归还；结果未知时不要反复派发，也不要删除记录后强行开始新会话。旧版仍持有控制或历史无法核验时，本版本会拒绝准备和升级，保留原始现场。

更新或卸载前先停止并等待独立归还，再正常退出持有运行组件的游戏。安装器还会检查当前记录；未通过时不应覆盖组件。设置、凭据、游戏和已部署 Mod 不随普通卸载删除。发生问题时从客户端导出诊断，分享前检查是否含本机路径或个人信息。

第三方组件清单及原许可位于安装目录 `runtime/notices` 和 `distribution-notices`；游戏和 Mod 的权利不由本安装包授予。此 beta 未包含自动更新能力。
