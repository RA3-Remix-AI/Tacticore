# 弈核 Tacticore v0.1.0-beta.2

Windows x64 界面改版预发布。本版按 main 的设计方向重整原生客户端，运行组件复用 beta.1 的原始冻结制品。

## 下载与安装

下载 `Tacticore_0.1.0-beta.2_x64-setup.exe`，核对附件 `SHA256SUMS.txt` 后按当前用户安装。安装器未数字签名，已附 Python 与运行依赖；首次安装 WebView2 可能需要联网。游戏和 Mod 需自行提供。

安装包 SHA-256：

```text
13f943917b7803a09a9dc8980da77519a8f4d8c712c7cbc946117774e5e180f3
```

## 本次更新

- 恢复侧边导航，将操作分为战前备战、作战中心、指挥官工坊、模型连接和运行记录。
- 备战页提供游戏与 Mod 的三步准备流程，以及模型连接和风格的准备进度。
- 作战中心突出当前下一步操作，区分发现、准备、检查、启动和停止归还。
- 全局保留吸顶的停止入口，切换工作区时保留配置草稿并回到页面顶部。
- 指挥官工坊提供打法卡片、五维偏好与场景说明；连接配置明确保留、替换和停用密钥的操作。
- 配置变化使旧检查结果失效，迟到的检查响应不会重新放开启动。

## 验证范围

源码与安装包对应提交 `c2afd5db66e2ca9948003c3a91f7d62798359f13`。Windows 自动构建成功，121 项前端测试、类型检查、Python 首用/查询/重开软件验证、Native6 软件验证及前后完整性预检通过；另有浏览器隔离交互验证与独立代码、产物复核。构建记录见附件 `ui-rebuild-provenance.json` 及探针报告。

本版未重新执行 Windows GUI 真实游戏验收，也未完成全新用户或干净虚拟机的安装验收。beta.1 的实机三局记录保留其原版本范围，不计作 beta.2 的新通过记录。本预发布用于收集新版界面的使用反馈，不作正式稳定版或完整实机验收通过的声明。

运行组件保持 beta.1 的原始字节，清单 SHA-256 为 `a43ab48b1daaf58f8e21091f609b6a7d669d3493e4d7f14946469e74210c1388`。发布步骤直接使用已核验的 beta.2 安装包，不再次重建；原始许可证随安装包提供。

## 兼容范围

支持已核验的 RA3 1.12 繁体中文配置、TemplePrime、P3 苏军与已验证出生位置、P4 原生电脑对手。模型连接使用自己的提供方、模型与密钥。文件摘要和对局设置仍参照 [beta.1 玩家说明](https://github.com/RA3-Remix-AI/Tacticore/blob/v0.1.0-beta.1/docs/windows-v0.1.0-beta.1-player-guide.md)；本版工作区入口以客户端内导航为准。

停止请求和控制归还分别核验；确认归还后仍须正常退出并重新打开游戏进程，再准备下一局。无自动更新。
