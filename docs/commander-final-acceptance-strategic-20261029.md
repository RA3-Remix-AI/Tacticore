# 指挥官最终验收目标：战略意图与原生 AI 执行

依据：用户 2026-10-29 重申的接管边界，以及“重新制定最终的验收目标，然后再执行联通”的指令。本文件替代旧下一阶段计划中与之冲突的精确建造、兵种数量和逐队列交付门槛；不改写任何历史实机记录。

## 最终产品目标

普通用户从客户端配置并启动一名模型指挥官。指挥官持续读取合法战况，判断打还是撤、是否侦察、是否扩张、是否推进或暂缓建设与生产，并根据反馈保持或调整战略。原生电脑 AI 自主选择建筑、落点、顺序、兵种、数量、搭配、协同及全部单位操作。

模型、适配器和执行器都不得把高层意图暗中变为指定建筑模板、指定兵种/数量、精确队列、任意坐标或逐单位指令。既有精细代码仅作为历史研究保留，不能因有旧资格就进入新的产品动作目录。

## 职责与语义

| 高层意图 | 指挥官决定 | 原生 AI 决定 | 必须说明的限制 |
| --- | --- | --- | --- |
| 进攻 / 防守 / 撤退 | 是否发起、保持、改变或结束高层任务 | 对象选择、招募、路线、阵型、交火与技能 | 接受任务不保证取胜或全军无损撤回 |
| 侦察 / 暂缓侦察 | 是否启动或停止额外侦察意图 | 侦察单位、目标、路径和操作 | 撤销额外偏好不等于关闭所有原生自主侦察 |
| 建设 / 暂缓建设 | 高层建设意图或经证明的原生整体建设策略门 | 具体建筑、顺序、落点、前置、排队和付款 | 预算偏好、撤销偏好、全局禁止新增建设是三种不同语义 |
| 补充兵力 / 暂缓 | 高层军备投入或经证明的整体生产策略门 | 兵种、数量、生产者、搭配和协同 | 不要求模型选择模板或精确配额 |
| 扩张 / 暂缓扩张 | 是否推动资源或基地扩张 | 合法扩张点、建设方案和保护行动 | 增加经济预算不能单独证明扩张意图已被采用 |
| 交还原生自主 | 撤销指挥官的额外偏好和任务 | 原生 AI 按自身规则继续 | 交还不等于命令原生停止建造、生产或战斗 |

每个入口必须公布它是偏好、任务还是整体策略门，并取得匹配语义的实机证据。现有接口无法表达某项意图时显示“未接通”，禁止以预算变化、固定建筑命令或仅显示按钮冒充实现。

## 最终必过项

| 编号 | 验收目标 | 通过证据 |
| --- | --- | --- |
| F01 接管边界 | 模型目录、请求、响应校验和最终派发均只允许高层意图 | 指定兵种/数量/建筑、坐标、单位任务等输入均在物理派发前拒绝；派发日志没有这些命令 |
| F02 战略判断 | 能根据合法战况保持/切换进攻、防守、撤退、侦察、扩张及建设/军备意图 | 威胁增加、兵力受损、资源压力、机会窗口和无效果场景选择合法意图或明确等待；风格不能扩大权限 |
| F03 原生联通 | 每个产品入口有真实原生采用/拒绝/等待反馈 | 真实模型意图、绑定身份、原生状态/任务/策略变化与采样时间串联；接受回执不作效果完成；缺失入口不得最终勾选 |
| F04 闭环与记忆 | 效果和阻碍进入下一轮判断，合理保持、改派或等待 | 至少一条有效效果链和一条等待/无效/条件失效后的重评链；不把连续重复派发当持续战略 |
| F05 日常客户端 | 配置、发现、预检、启动、观察、停止、诊断和下一局可实际操作 | 普通路径无需手改会话文件；状态与真实宿主相符；明确显示意图等待与未接通原因 |
| F06 生命周期 | 身份、视野、时效、输入边界及停止归还可靠 | 旧局/旧配置/迟到回复拒绝；未知不盲重发；停止后零新增请求和指挥；失联和异常清理有独立证据 |
| F07 综合自然局 | 同一冻结候选完成三局普通风格自然结算 | 无按秒指定动作、无脚本代替模型选战略、全程生命周期观察、真实请求/执行/反馈/结算/归还及诊断录像齐全 |

三局允许胜或负，不以胜率证明产品质量。各意图的分项可控场景与三局综合表现分开验证，不强迫每局出现所有意图；失败或中断局保留，修复后补齐。缺少建设、生产或扩张的高层原生入口仍是功能缺项，但不再以“必须造出某建筑或某数量牛蛙”替代它。

## 不作为本期完成门槛的旧项目

逐建筑新增消费者、特定兵种及精确数量、每笔付款退款、模型独占出厂归因、单兵移动/射击、全军无损撤回不再是本期产品验收目标。必要的内部只读诊断仍可使用，但不能据此扩张接管权限或让其取代上述 F01–F07。

## 联通执行顺序

1. 先让现有活动研究按原合同完成停止和归还；唯一游戏由一个执行者持有。
2. 产品 Host 默认采用战略边界：能力目录剔除所有精确建造/生产动作，生产选择固定交原生，响应与最终派发双重校验；新依赖纳入原来的文件冻结和授权重核。
3. 先复用已有资格的进攻、防守、撤退、侦察和发展优先级入口，确认新模型合同到原生的真实短窗；不继承旧精细能力的产品权限。
4. 为建设/生产整体策略及扩张寻找真正的原生高层入口，逐项证明实际语义。缺项保持未接通，不给模型虚假权限。
5. 在真实客户端完成正常路径、重评及停止后，冻结候选，再运行三局。历史研究局不补计为新验收局。
